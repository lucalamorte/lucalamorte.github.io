Ask the warehouse

A business question in plain English goes in, and the answer comes back from the company's own data. This is an early write-up of a product being built now.

Built with

  • Snowflake
  • Cortex Agents
  • Cortex Analyst
  • Cortex Search
  • Semantic model
  • Cortex Code

The idea

Most questions about a business are already answered somewhere in its warehouse or its documents. The hard part is knowing where.

How a question is answered

A questionwhich campaign won Q3?
The agent picks a toolCortex Agents decides between tables and documents
Cortex Analystturns the question into SQL over a semantic model
Cortex Searchfinds the passages that answer it in documents
The answer, with its sourcethe table or the document behind every number

Design rules

  • The model reads, the code decides: numbers come from SQL over the semantic model, never from the model's memory.
  • One definition per metric: the semantic model is the only place where a metric is defined.
  • Always cite: an answer without a source is not shown.
