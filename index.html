How I work

From the first conversation about a metric to the bug report six months later.

  • DefineAgree on how a metric is calculated before anyone builds a dashboard.
  • DesignKeep one copy of the data, in the warehouse, and every rule in one place.
  • BuildLet the model read what people mean; let code do every number and date. No hardcoded lists.
  • TestUse it the way a real user would before calling it done.
  • ShipRoll out one plant at a time, and train the team before moving on.
  • RunCheck data quality inside the pipeline, so bad data never reaches a user.
  • LearnTurn every real failure into a test, so it only happens once.
  • TeamWrite it so the next person can audit it, and reuse before rewriting.
